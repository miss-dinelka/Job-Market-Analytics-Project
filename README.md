====================================================

## Project Title:

Job Postings Analytics Dashboard

====================================================

## Description:

A data analytics project analyzing 10,000 technology job postings using SQL, Excel/Power Query, and Power BI.

====================================================

## Objective:

Analyze job-posting data to identify trends in job demand, salaries, required skills, remote-work opportunities, industries, and company characteristics.

====================================================

## ⚠️ Data Source & Disclaimer:####

**Source:** This dataset was obtained from [Kaggle](https://www.kaggle.com/datasets/ahsanneural/future-jobs-and-skills-demand-2025).
**Nature of Data:** This is synthetic / imaginary data generated solely for demonstration, educational, and analytical practice purposes.
**Disclaimer:** The metrics, figures, and trends in this dataset **do not reflect real-world industry demand**, actual market conditions, or real operational data. They should not be used for business decision-making or real-world forecasting.

The dataset consists of 10,000 rows and 9 columns as given below.

# Job title

# Industry

# Location

# Salary

# Required skills

# Remote option

# Company size

# Posting date
